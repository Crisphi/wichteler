# Version 2024 - Webwichteler

Nach drei Jahren Stille wird der Wichteler wiederbelebt um Wichtel zu erfreuen! 
Ziel ist eine Web-App für eine streamlined und skalierbare Wichtel-Experience

## Features:
* *NEU* Registrierung und Anmeldung
* *NEU* Verwaltung der Daten in einer Datenbank
* *NEU* Web-Interface, in dem die Teilnehmenden ihre Daten selbst eintragen können
* Automatisches Auslosen der Teilnehmenden
* Automatisches Versenden der Wichtelpartner:innen per Mail mit Adressinformationen
* Blacklists für die einzelnen Teilnehmenden, in der Personen vermerkt werden, die man nicht kennt
